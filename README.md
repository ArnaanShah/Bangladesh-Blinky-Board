 # Bangladesh-Blinky-Board  
A Simple LED chaser in the shape of the flag of Bangladesh based on the Blinky Board tutorial from Stasis. The 10 red LEDs are arranged along the circle of the Bangladesh flag. There is a red 3d printed part to cover the white silkscreen and make the PCB resemble the flag more. This was a very fun simpler project to make and I liked that I could include something personal to me in it. It taught me how to use analog sensors. 

# Setup
The setup is very quick and can be done in 4 steps:

1. Order your PCB from [JLCPCB](https://jlcpcb.com)
2. Solder the components onto the board
3. Place the 3d printed circle on top of the LED ring
4. Power on your blinky board!

# PCB
The PCB was made in KiCad and it was very easy because most of the instructions were given by the tutorial. The schematic was a bit tricky because some of the individual part schematics looked different, but I was able to figure it out. Making the layout of the PCB made me learn how to use the array tool in KiCad. The routing was simple and I tried arranging the rest of the components in a way that would look nice.
